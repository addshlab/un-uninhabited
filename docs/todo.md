# やりたいことリスト

## 天気の概念の追加（実装済み）

- [x] 毎時0分から10分ごとに天気の抽選を行う
- [x] 天気ごとの抽選確率
  - 晴れ: 70%
  - 雨: 25.99%
  - 嵐: 4%
  - 雪: 0.01%

## イベントの概念の追加

- イベント設定は `data/events.json` に記載する
- イベント設定に以下の項目を持たせる
  - イベントID
  - イベント名
  - 発生タイプ（ランダム発生頻度または日付）
- 個別のイベントをファイルごとに書き出して管理するか検討する
- イベント例
  - 流れ星
    - 夜のみ20%の確率で発生する
    - 発生した翌朝に「彗星の欠片」が漂着する

## クラフトシステムの追加

- 設計: [`spec/crafting-system-design.md`](../spec/crafting-system-design.md)

- レシピは `data/craft_recipies.json` に記載する
- インベントリの初期容量は16個にする
- インベントリを以下のクラフトで拡張できるようにする
  - 流木 × 8 → 大きい木の箱（容量32）
  - 流木 × 16 → 大きい木の箱（容量64）
  - レンガ × 800 → サイロ（容量2000）
  - 惑星のコア × 1 + 宇宙ひも × 1 → ワームホール（容量9999）
