# 無人島ゲーム 現行仕様書

## 1. 文書の目的

本書は、`mockup/` に実装されている無人島ゲームの現行仕様を記録する。将来構想ではなく、現在動作するモックアップを対象とする。

## 2. システム概要

- ブラウザで動作する、1画面構成のシングルプレイヤー向けモックアップである。
- プレイヤーは砂浜へ流れ着くアイテムを回収し、インベントリで管理できる。
- インベントリのアイテムは砂浜へ戻せる。
- ゲーム進行、アイテム、インベントリの状態はメモリ上だけに保持し、保存や復元は行わない。
- HTML、CSS、JavaScriptおよびJSONだけで構成し、外部ライブラリは使用しない。

## 3. 起動要件

アイテム定義を `fetch` で取得するため、`mockup/` をドキュメントルートとするローカルHTTPサーバーが必要である。

```bash
cd mockup
python3 -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000` を開く。`index.html` をファイルとして直接開いた場合は、ブラウザのセキュリティ制限によってアイテム定義を取得できない場合がある。

## 4. 画面仕様

### 4.1 全体レイアウト

- ゲーム画面のアスペクト比は16:9、最大表示幅は960pxである。
- マップは内部解像度384×216pxのCanvasに描画し、ドット絵調で拡大表示する。
- 画面右側35%をインベントリ領域とし、左側を操作可能なマップ領域とする。
- マップには海、砂浜、島内の草地、ヤシ、岩、茂み、焚き火を描画する。
- 海面と波打ち際はアニメーションする。
- 横幅700px以下の端末を縦向きで表示した場合、ゲーム画面を隠して横向きへの回転案内を表示する。

### 4.2 ヘッダーと状態表示

- タイトルとして「無人島 / DAY 1」を表示する。日数を進行させる機能はない。
- 状態欄には直近の操作結果または案内、おおよその次回漂着までの秒数、砂浜上のアイテム数を表示する。
- 操作メッセージは原則5秒間表示し、その後は通常案内へ戻る。

### 4.3 操作ボタン

- **＋ 漂着物**: 動作確認用に漂着処理を即時実行する。アイテム定義の読み込み完了まで無効である。
- **波 ON/OFF**: 海面と波打ち際のアニメーションを切り替える。漂着間隔や消滅時間には影響しない。
- **＋4枠**: インベントリ容量を4枠拡張する。最大容量に達すると無効になる。
- **選択解除**: インベントリで選択中のアイテムを未選択に戻す。未選択時は無効である。

## 5. 漂着物仕様

### 5.1 初期配置と自動漂着

- アイテム定義の読み込み完了時に3個の漂着物を砂浜へ配置する。
- 以後はタイマーによって1個ずつ自動配置する。
- 基本漂着間隔は15秒、最短8秒、最長30秒である。
- 次回間隔は基本間隔の0.6倍以上1.6倍未満の範囲からランダムに算出し、上下限内に丸める。
- 直前の間隔が15秒未満だった場合は、次回の算出値を1.25倍して短い間隔の連続を抑制する。
- 手動の「＋ 漂着物」操作は、自動漂着タイマーをリセットまたは延期しない。

### 5.2 アイテム抽選

- アイテムは `mockup/data/items.json` の `weight` を用いた重み付き抽選で決定する。
- `weight` が大きいアイテムほど選ばれやすい。
- `rarity` は定義情報として保持するが、抽選処理は `weight` のみを参照する。

### 5.3 配置制約

- 漂着物を配置できるのは、マップ左側の操作可能範囲内にある砂浜だけである。
- 砂浜に同時に存在できるアイテムは最大12個である。
- 自動・手動漂着時に上限へ達していた場合、新しいアイテムは配置しない。
- 新しい漂着位置は最大30回試行し、既存アイテムとの距離が15px以上となる位置を探す。配置可能な位置を得られない場合は配置しない。

### 5.4 消滅

- 各アイテムは定義された `despawnSeconds` の経過後に砂浜から消滅する。
- 消滅10秒前から約300ms周期で点滅する。
- インベントリから砂浜へ再配置したアイテムの消滅時刻は、再配置時点から改めて計算する。
- 波アニメーションを停止しても消滅タイマーは停止しない。

## 6. アイテム操作

### 6.1 回収

- 砂浜上のアイテムをクリックすると、そのアイテムをインベントリへ移動する。
- アイテム中心から9px以内をクリック対象として扱う。
- インベントリが満杯の場合は回収せず、アイテムを砂浜に残す。
- 回収成功時はアイテム名と説明を状態欄へ表示する。

### 6.2 選択と再配置

- インベントリの使用中スロットをクリックするとアイテムを選択できる。
- 選択中のスロットを再度クリックするか、「選択解除」を押すと選択を解除する。
- 選択中に砂浜をクリックすると、アイテムをインベントリから砂浜へ移動する。
- 砂浜以外をクリックした場合、砂浜が12個で満杯の場合、または既存アイテムから15px未満の位置を指定した場合は配置せず、選択状態とインベントリ内のアイテムを維持する。
- 漂着物自体をクリックした場合は、選択アイテムの配置よりも、その漂着物の回収を優先する。

## 7. インベントリ仕様

- 初期容量は8枠である。
- 1回の拡張につき4枠増加する。
- 最大容量は24枠である。
- 画面上のグリッドは4列で、容量に応じて8～24個のスロットを表示する。
- アイテムは1個につき1枠を使用し、スタックしない。
- 空きスロットは「空き」と表示し、操作できない。
- 並び替え、破棄、アイテム使用、クラフトの機能はない。

## 8. アイテムデータ仕様

アイテム定義ファイルは次の構造を持つ。

```json
{
  "items": [
    {
      "id": "driftwood",
      "name": "流木",
      "type": "wood",
      "rarity": "common",
      "weight": 30,
      "description": "工作や焚き火に使えそうな流木",
      "despawnSeconds": 75
    }
  ]
}
```

| フィールド | 用途 |
| --- | --- |
| `id` | アイテム種別の識別子 |
| `name` | 画面に表示する名称 |
| `type` | Canvas上の描画パターン |
| `rarity` | レアリティを示す定義情報 |
| `weight` | 漂着時の重み付き抽選に用いる正数 |
| `description` | 回収時のメッセージおよびスロットの補足情報 |
| `despawnSeconds` | 砂浜へ配置してから消滅するまでの秒数 |

現行データには、流木、小枝、貝殻、ヤシの実、空き瓶、布切れ、ロープ、漁網、木箱、古びた鍵の10種類がある。

## 9. 初期化とエラー処理

- 起動時はインベントリを描画した後、`mockup/data/items.json` を読み込む。
- `items` が配列ではない場合、または空の場合は初期化失敗として扱う。
- 読み込みに失敗した場合は状態欄にエラーとHTTPサーバーからの起動案内を表示する。
- 読み込み失敗時は漂着ボタンを有効化せず、初期配置および自動漂着を開始しない。

## 10. 現行モックアップの対象外

次の機能は現行実装に含まれない。

- セーブ、ロードおよびサーバーとの状態同期
- 日数や時間帯の進行
- プレイヤーキャラクターの移動
- 体力、空腹度などのサバイバルパラメーター
- アイテムの使用、クラフト、建築
- 音声、BGM
- キーボードまたはゲームパッド専用操作
- 自動テストおよびビルド工程
