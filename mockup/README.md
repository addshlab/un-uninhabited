# 無人島ゲーム Mockup

## 起動方法

アイテム定義JSONを読み込むため、ローカルHTTPサーバーから起動します。

```bash
cd mockup
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いてください。

> `index.html` を直接開くと、ブラウザのセキュリティ制限によりJSONを読み込めない場合があります。

## 遊び方

- 砂浜の漂着物をクリックするとインベントリに取得できます。
- インベントリが満杯の場合、漂着物は取得できず砂浜に残ります。
- インベントリ内のアイテムを選び、砂浜をクリックすると再配置できます。
- 漂着物は種類ごとの制限時間を過ぎると波にさらわれます。消滅10秒前から点滅します。
- 「容量を4枠拡張」で、インベントリを初期8枠から最大24枠まで拡張できます。
- 「漂着物を流す」は動作確認用に、次の漂着を待たずアイテムを追加するボタンです。

## 漂着の仕組み

- アイテムは `data/items.json` に定義されています。
- `weight` の値を使った重み付き抽選で、レアなアイテムほど出現しにくくなっています。
- 漂着間隔は基本15秒、最短8秒、最長30秒です。
- 毎回ランダムに次の間隔を計算し、短い間隔が続きすぎないよう補正します。
- 砂浜には最大12個まで存在でき、満杯の場合、新しい漂着物は追加されません。

## 内容

- HTML + JavaScriptのみ
- 外部ライブラリ不要
- 256x256px Canvas
- ドット絵風の海、砂浜、島内部
- 波と焚き火の炎のアニメーション
- JSONによるアイテム定義
- 重み付き抽選とランダムな漂着間隔
- 時間経過による漂着物の消滅
- 拡張可能なインベントリ
- インベントリと砂浜の間のアイテム移動
